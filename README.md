## 📌 1. สรุปรายละเอียดงานเลี้ยงรุ่น NCO.1828

- **ชื่องาน:** ขอเชิญร่วมงานเลี้ยงรุ่น NCO.1828 เหล่าทหารปืนใหญ่ "กลับบ้านที่ลพบุรี แหล่งกำเนิดของพวกเราทุกคน"
- **วันจัดงาน:** วันศุกร์ที่ 19 กุมภาพันธ์ 2570
- **สถานที่:** ณ โรงแรมโตเกียว จ.ลพบุรี
- **ธีมงาน:** แต่งชุดไทย ร่วมสัมผัสบรรยากาศงานแผ่นดินสมเด็จพระนารายณ์
- **ระยะเวลาลงทะเบียน:** 1 สิงหาคม 2569 – 31 ธันวาคม 2569
- **สิทธิพิเศษ:** 🎁 50 คนแรกที่ตอบรับและโอนเงินลงทะเบียน รับฟรี **พวงกุญแจ 1828 (ลายกระสุน/ระเบิด)** 1 ชิ้น

### 🎁 สิ่งที่จะได้รับในงาน
1. เสื้อโปโล WARRIX 1828 Artillery ลายผ้าไทย 1 ตัว
2. อาหารมื้อเย็น 1 มื้อ และ มื้อเช้า 1 มื้อ
3. สิทธิ์ลุ้นของรางวัล วงเงิน 10,000 บาท
4. สิทธิ์ชิงโชคค่าน้ำมัน วงเงิน 10,000 บาท

## 🚀 6. วิธีการติดตั้งใช้งาน Google Apps Script Web App

1. เปิดไปที่ Google Sheets: [https://docs.google.com/spreadsheets/d/1N4E2U1sXdU7HMCDASg5s8hxceXLJ_aRigan-pYsh-p0/edit](https://docs.google.com/spreadsheets/d/1N4E2U1sXdU7HMCDASg5s8hxceXLJ_aRigan-pYsh-p0/edit)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `Code.gs` วางลงในเอดิเตอร์ Apps Script
4. กดปุ่ม **ทำรายการใหม่ (Deploy)** -> **การทำให้ใช้งานได้ใหม่ (New deployment)**
5. เลือกประเภท: **เว็บแอป (Web App)**
   - **Execute as:** Me (อีเมลของคุณ)
   - **Who has access:** Anyone (ทุกคน)
6. กด **Deploy** และอนุมัติสิทธิ์ (Grant Permissions)
7. คัดลอก **Web App URL** ที่ได้ (ตัวอย่าง: `https://script.google.com/macros/s/.../exec`)
8. เปิดไฟล์ `index.html` แล้วนำ URL ไปวางแทนที่บรรทัด:
   ```javascript
   const SCRIPT_URL = "นำ URL Web App มาวางที่นี่";
   ```
9. สามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์หรืออัปโหลดขึ้นเว็บโฮสติ้งใช้งานได้ทันที!
